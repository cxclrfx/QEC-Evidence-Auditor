# Evaluation and Licensing

QEC Evidence Auditor — Standard Mathematical V1 is a privately distributed software product with a technical showcase.

## Evaluation process

1. Define the mathematical claim or data-integrity question to test.
2. Confirm that the input falls into one of the five supported scopes.
3. Agree on a private evaluation package and a bounded acceptance criterion.
4. Execute the evaluation on synthetic or authorized datasets.
5. Review independent verifier results and explicitly record limitations.

## Package availability

Source code, executable builds and research-only material are **not** attached to this repository. Access to a private evaluation or commercial package requires a separate agreement with the repository owner.

## Contact

Authorized collaborators may use this private repository's Issues for a non-confidential initial inquiry. External access and evaluation terms must be arranged with the owner; no public contact address is supplied here.

**Do not post proprietary datasets, device logs, encryption keys, or unpublished findings in a public issue.**

## Licensing

This repository is a documentation-only showcase. No license to use or redistribute the underlying software is granted by publication of these materials.
