# Scientific Scope and Boundaries

The product is a **mathematical-evidence checker** within explicitly defined inputs, not a universal hardware certification system.

| Mode | Supported evaluation | Not established |
|---|---|---|
| `claims` | Supported declared claims and witness classes | Absence of every possible QEC failure |
| `css` | GF(2) matrix compatibility, ranks and syndromes | General code distance, live logical-error suppression |
| `data` | Row identity, differences and key ambiguity | Completeness or authenticity of upstream laboratory exports |
| `finite` | Full examination of the *supplied* finite model | Physical completeness of that model |
| `residual` | Declared bounded modular calculations | A general SHA-256 or quantum-hardware certificate |

### Qualification boundaries

- Results are controlled by input schemas and their declared semantics.
- Laboratory hardware claims require validated adapters and trusted measurements.
- Recorded internal tests are not third-party certification.
- No new real-hardware holdout or external scientific benchmark is claimed for this release.
- There may be multiple mathematically correct witnesses for one linear-algebra problem; byte-identical witness output is not required for mathematical equivalence.

### Method disclosure

The repository describes externally observable capabilities and broad conventional mathematical foundations, **not** private scientific models, proprietary research proofs, unpublished hardware analyses or the source implementation.
