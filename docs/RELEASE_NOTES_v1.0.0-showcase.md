# QEC Evidence Auditor — Standard Mathematical V1 | Technical Showcase

**Tag:** `v1.0.0-showcase` · **Date:** 15 October 2026

A documentation-only showcase of local offline QEC evidence auditing. Auditor produces scoped mathematical findings; a separate Verifier recalculates supported findings against the declared input and submitted evidence.

Five modes: **claims**, **css**, **data**, **finite**, **residual**.
