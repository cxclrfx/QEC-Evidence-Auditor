# Roadmap

The following work is proposed, not completed or promised on a fixed schedule.

1. Define a licensed evaluation package with exact build identity, input contracts and run instructions.
2. Provide a redacted, distributable execution-evidence bundle where permitted.
3. Arrange an independently administered evaluation on fresh cases after build freeze.
4. Qualify any dataset adapters separately, including row identity and provenance assumptions.
5. Consider a runnable, source-protecting demonstration after licensing and disclosure review.

Public launch and external announcements require owner authorization. This repository remains private. Physical decoder performance and hardware certification require separate scientific evidence.
